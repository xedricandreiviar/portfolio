# Daily Money Tracker

Personal finance app for logging daily expenses, categorizing spending, and visualizing where money goes. Built with Next.js and TypeScript, styled with Tailwind CSS. The goal was something I'd actually use every day — quick entry, clear breakdowns, no bloat.

Currently deployed at [xedmoneytracker.vercel.app](https://xedmoneytracker.vercel.app).

## Stack

Next.js, TypeScript, Tailwind CSS

## Running locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Opens on `localhost:3000`. No external database required for the basic version — data persists in localStorage.
